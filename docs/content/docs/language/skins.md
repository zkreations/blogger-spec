Blogger templates manage dynamic styling and Theme Designer customizations through specialized CDATA sections inside `<b:skin>` and `<b:template-skin>`. This specification defines the syntax of Theme Designer XML tokens, the compound properties exposed by font and background variables, and the multi-phase CSS compilation pipeline executed by `compileSkinCss`.

## Theme Designer Tags

- **`<Variable>`:** Declares an editable theme token with attributes `name`, `description`, `type`, `value`, and `default`.
- **`<Group>`:** Organizes variables into visual groups within the Blogger Theme Designer UI.

{{< hint warning >}}
**Strict CDATA Location (`BX1023`):** `<Variable>` and `<Group>` tags must reside strictly within `<b:skin>` CDATA blocks. They are forbidden in `<b:template-skin>`, generic CDATA sections, or the template `<body>`.
{{< /hint >}}

## Compound Properties

Theme variables expose sub-properties when evaluated inside CSS or external expressions:

- **Font variables (`skin:font`):** Expose `.size`, `.family`, `.weight`, and `.style`.
- **Background variables (`skin:background`):** Expose `.color`, `.image`, `.repeat`, `.attachment`, and `.position`.
- **Color variables (`skin:color`):** Expose `.red`, `.green`, `.blue`, and `.alpha`.

## Compilation Pipeline

Compilation processes `<b:skin>` CDATA in sequential phases:

1. **XML Flow Directives:** Directives like `<b:if>`, `<b:switch>`, and `<b:with>` inside the skin CDATA are evaluated first.
2. **Metadata Stripping:** `<Variable>` and `<Group>` definitions are parsed and removed from the resulting CSS.
3. **Variable Substitution:** References formatted as `$(variable.name)` are substituted with resolved theme values.
4. **Style Wrapper:** Wraps the compiled stylesheet in legacy comment blocks.

Output format generated by `compileSkinCss`:

```html
<style id='page-skin-1' type='text/css'><!--
/* Compiled CSS output */
--></style>
```
